## ProdigyInfoTech-Data-Science-internship
I mastered data cleaning and EDA with Pandas/Seaborn, built and evaluated Decision Tree models using Scikit-Learn, and applied NLP via TextBlob for sentiment analysis. Additionally, I analyzed temporal and geospatial datasets to uncover traffic patterns, successfully completing a comprehensive end-to-end data science internship


Below is an overview of the 5 tasks completed in this portfolio, along with direct links to each project:

---

 Task 1: Population Data Visualization
Objective: Explored and visualized demographic trends and population metrics.
Tools Used: Python, Pandas, Matplotlib, Seaborn.
Key Insights: Generated histograms and bar charts to identify population distribution patterns, density clusters, and outliers across datasets. Project Link: [Paste Task 1 Link Here] https://github.com/mdrashidbodi786-stack/ProdigyInfoTech-Data-Science-internship/blob/main/task1.ipynb

 Task 2: Titanic Data Cleaning & Exploratory Data Analysis (EDA)
Objective: Cleaned raw datasets and uncovered survival patterns based on passenger attributes.
Tools Used: Pandas, Data Imputation, Seaborn.
Key Insights: Discovered strong statistical correlations showing that female passengers, first-class ticket holders, and higher fare brackets had significantly higher survival rates.
Project Link: [Paste Task 2 Link Here] https://github.com/mdrashidbodi786-stack/ProdigyInfoTech-Data-Science-internship/blob/main/task%202.ipynb

 Task 3: Decision Tree Classifier (Predictive Modeling)
 Objective: Built a supervised machine learning classification model to predict categorical outcomes.
 Tools Used: Scikit-Learn, One-Hot Encoding, Train-Test Splitting.
 Key Insights: Trained a Decision Tree model achieving strong predictive accuracy (~81%), evaluated rigorously using a classification report and     a confusion matrix heatmap.
 Project Link: [Paste Task 3 Link Here] https://github.com/mdrashidbodi786-stack/ProdigyInfoTech-Data-Science-internship/blob/main/task%203.ipynb

 Task 4: Social Media Sentiment Analysis
 Objective: Analyzed and visualized public opinion and sentiment patterns from text data.
 Tools Used: Natural Language Processing (NLP), TextBlob, Seaborn Countplots.
 Key Insights: Automated polarity scoring to categorize public feedback into *Positive*, *Neutral*, and *Negative* groups, visualizing emotional     weight distribution.
 Project Link: [Paste Task 4 Link Here] https://github.com/mdrashidbodi786-stack/ProdigyInfoTech-Data-Science-internship/blob/main/task%204.ipynb

 Task 5: Traffic Accident Data Analysis & Hotspot Mapping
 Objective: Analyzed traffic accident patterns related to road conditions, weather, and time of day.
 Tools Used: Datetime Feature Extraction, Geographic Scatter Plotting.
 Key Insights: Identified peak accident frequency spikes during morning and evening rush hours (7–9 AM and 4–6 PM) and mapped high-density           spatial clustering coordinates.
